👨‍🎓 Data Siswa

Master data siswa — sumber data untuk penempatan Locker Siswa. Naik kelas tidak perlu mengubah data locker satu-satu, cukup perbarui data siswa di sini.

Format Excel Import: kolom studentId (atau NIS/NISN), nama, jenjang, kelas, status (status: Aktif / Nonaktif) — nama kolom boleh pakai spasi atau tidak, huruf besar/kecil bebas. Jika studentId sudah ada, datanya akan diperbarui (nama/jenjang/kelas/status); jika baru, akan ditambahkan otomatis. Riwayat locker siswa lama tidak akan terhapus meskipun statusnya diubah menjadi Nonaktif.

🗄️ Data Locker

Master inventaris unit locker dan kunci.

Format Excel Import: kolom Locker ID / lockerId, Nomor Kunci / nomorKunci, Kondisi / kondisi — nama kolom boleh pakai spasi atau tidak, huruf besar/kecil bebas. Nilai Kondisi selain "Baik" / "Rusak Ringan" / "Rusak" (misal "Belum Kembali", "Kosong") akan otomatis dianggap "Baik". Cocok untuk memasukkan puluhan/ratusan unit locker sekaligus di awal.
